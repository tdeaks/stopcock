# @stopcock/persistent

## 2.0.0-next.0

### Minor Changes

- 5db6fca: Add a publishable persistent collection suite with structurally shared vector,
  HAMT map/set, insertion-ordered variants, queues, deques, stacks, custom
  hash/equality strategies, and sealed transient builders for bulk construction.

## 0.1.0

- Add immutable `Vector`, `HashMap`, `HashSet`, `OrderedMap`, `OrderedSet`,
  `Queue`, `Deque`, and `Stack` collections.
- Add custom hash/equality strategies and JavaScript-compatible default key
  semantics.
- Add explicitly mutable, one-shot builders for bulk construction.
