Everything you need for pipe-based FP. Arrays, strings, objects, numbers, and typed error handling. Chain streaming array operations in `pipe` and they get fused into single loops at runtime.

```ts
import { pipe, A, O, R } from '@stopcock/fp'

const activeNames = pipe(
  players,
  A.filter((p) => p.active),
  A.map((p) => p.name),
  A.take(10),
)
```

- `pipe(value, ...fns)` passes a value through functions left to right. Streaming `A.*` operations can fuse into a single loop.
- Every function works **both ways**: `A.map(arr, fn)` (data-first) and `pipe(arr, A.map(fn))` (data-last).
- `Option<A>` / `Result<A, E>` cover nullable values and recoverable errors. Numeric `_tag` values support fast branching.

```ts
// Looks like 3 passes over the array:
const result = pipe(
  users, // 100,000 users
  A.filter((u) => u.active), // pass 1: filter
  A.map((u) => u.name), // pass 2: map
  A.take(10), // pass 3: slice
)

// But streaming fusion compiles it into roughly:
const result = []
for (const u of users) {
  if (!u.active) continue
  result.push(u.name)
  if (result.length >= 10) break
}
```

<Aside type="tip">
  Streaming-fused operations include `map`, `filter`, `flatMap`, `take`, `drop`, `takeWhile`, and `dropWhile`.
  Terminal folds and predicates such as `reduce`, `find`, `every`, `some`, and `count` finish a fused pass.
  Accessor terminals such as `head`, `last`, `length`, `join`, `sum`, `min`, and `max` also end the chain.
  `sort`, `sortBy`, `reverse`, `groupBy`, and `uniq` are materialization boundaries.
  `sortBy -> take(k)` and `sort -> take(k)` use a special top-k optimization.
</Aside>

## Option & Result

```ts
// Option: values might not exist
const port = pipe(
  O.fromNullable(process.env.PORT),
  O.map((s) => parseInt(s, 10)),
  O.filter((n) => n > 0 && n < 65536),
  O.getOrElse(() => 3000),
)

// Result: operations might fail
const config = pipe(
  R.tryCatch(() => JSON.parse(rawConfig)),
  R.map((obj) => obj.settings),
  R.getOrElse(() => defaults),
)
```

<Aside type="note">
  `Option` and `Result` use numeric `_tag` values (0/1) instead of string tags. V8 handles numeric
  comparisons in a single CPU instruction.
</Aside>
