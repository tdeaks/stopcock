`@stopcock/synth` turns audio patches into serializable value graphs. Sources,
filters, envelopes, effects, modulation, stereo routing, and voices are just
nodes; renderers materialize them for offline buffers, Web Audio, or generated
AudioWorklet processors.

The [Spectral Optimizer](/showcases/spectral-optimizer/) shows synth in the
middle of the full stack: autodiff tunes a patch, signal verifies it, and
svg/color turn the result into a generated artifact.

## Core shape

Compose the graph with `pipe()`, then choose a renderer. The offline renderer is
deterministic and returns typed arrays, which makes snapshots, tests, and WAV
exports boring in the best way.

```ts
import { pipe } from '@stopcock/fp'
import { effects, envelope, filter, oscillator, render, toWav } from '@stopcock/synth'

const bass = pipe(
  oscillator('saw', 110),
  filter.lowpass(800, 0.7),
  envelope({ attack: 0.01, decay: 0.3, sustain: 0.4, release: 0.5 }),
  effects.distortion(0.3),
)

const samples = render(bass, {
  duration: 2,
  sampleRate: 48000,
  triggers: [
    { midi: 36, velocity: 0.9, atSec: 0, gateMs: 220 },
    { midi: 43, velocity: 0.7, atSec: 0.5, gateMs: 180 },
  ],
})

const wav = toWav(samples, { sampleRate: 48000 })
```

<Aside type="tip">
  Nodes are plain objects. The graph walker freezes object wrappers at compile
  time, but typed-array fields such as buffers and impulse responses stay
  caller-owned.
</Aside>

## Bicep-inspired pluck

The `Euphoric pluck` preset in the console is an original loop that behaves like
a keyboard arpeggiator: hold one root note, move up a tone, push a further
semitone higher, then fall down a tone, with occasional octave taps. The
patch itself uses a bell-like triangle core, octave sine glint, detuned saw air,
pink-noise texture, highpass into a resonant lowpass, a short pluck envelope,
wide chorus, and a tempo-synced dotted delay.

```ts
import { pipe } from '@stopcock/fp'
import { effects, envelope, filter, gain, mix, noise, oscillator, pan, render, toWav } from '@stopcock/synth'

const bpm = 128
const bars = 4
const hpSweep = 0.55
const hpRate = 1
const sampleRate = 24000
const stepSec = 60 / bpm / 2
const cycles = bars / 2
const root = 66
const octave = root + 12
const upTone = root + 2
const upToneSemi = root + 3
const downTone = root - 2
const pedalFor = (cycle: number) => root + ([0, 2, -2, 3][cycle % 4] ?? 0)

const pluck = pipe(
  mix([
    pipe(oscillator('triangle', 110), gain(0.82)),
    pipe(oscillator('sine', 110, { detune: 1200 }), gain(0.16)),
    pipe(oscillator('saw', 110, { detune: 11 }), gain(0.28)),
    pipe(oscillator('saw', 110, { detune: -15 }), gain(0.18)),
    pipe(noise('pink', { seed: 1138 }), gain(0.025)),
  ]),
  filter.highpass(145, 0.7),
  filter.lowpass(4550, 1.8),
  filter.peak(1450, 0.9, 3.2),
  envelope({ attack: 0.018, decay: 0.26, sustain: 0.19, release: 0.36 }),
  effects.distortion(0.06, 'tanh'),
  effects.ensembleChorus({ rate: 0.34, depth: 4.44, mix: 0.4, width: 1, noise: 0.04 }),
  effects.tapeDelay({ timeMs: 45_000 / bpm, feedback: 0.5, mix: 0.5, wow: 0.18, flutter: 0.08, tapeAge: 0.28 }),
  effects.plateReverb({ preDelayMs: 10, decay: 0.5, damping: 0.38, diffusion: 0.72, modulation: 0.16, mix: 0.18 }),
  effects.springReverb({ decay: 0.54, damping: 0.4, tension: 0.46, drip: 0.18, mix: 0.08 }),
  effects.nonlinearReverb({ timeMs: 120, decay: 0.58, damping: 0.34, drive: 0.16, mix: 0.06 }),
  effects.compressor({ threshold: -18, ratio: 2.4, attack: 0.004, release: 0.18, knee: 18 }),
  pan(0.08),
)

const pattern = [
  root, root, upTone, octave,
  root, upToneSemi, upTone, downTone,
  root, upTone, octave, upToneSemi,
  upTone, root, downTone, root,
]
const triggers = Array.from({ length: cycles }, (_, cycle) =>
  pattern.map((midi, index) => {
    const pedal = pedalFor(cycle)
    return {
      midi:
        midi === root ? (cycle % 2 === 1 && [1, 9].includes(index) ? pedal + 12 : pedal)
        : midi,
      atSec: (cycle * pattern.length + index) * stepSec,
      gateMs: stepSec * 380,
      velocity: index % 8 === 0 ? 0.96 : 0.62,
    }
  }),
).flat()

const highpassMotion = (input: Float32Array, duration: number) => {
  const out = new Float32Array(input.length)
  let prevInput = 0
  let prevOutput = 0
  for (let i = 0; i < input.length; i++) {
    const phase = (2 * Math.PI * hpRate * (i / sampleRate)) / duration
    const cutoff = 42 + (1650 - 42) * hpSweep * (0.5 - 0.5 * Math.cos(phase))
    const rc = 1 / (2 * Math.PI * cutoff)
    const alpha = rc / (rc + 1 / sampleRate)
    out[i] = alpha * (prevOutput + input[i] - prevInput)
    prevInput = input[i]
    prevOutput = out[i]
  }
  return out
}

const duration = pattern.length * stepSec * cycles + 1.25
const raw = render(pluck, { duration, sampleRate, triggers })
const samples = Array.isArray(raw)
  ? [highpassMotion(raw[0], duration), highpassMotion(raw[1], duration)]
  : highpassMotion(raw, duration)

const wav = toWav(samples, { sampleRate })
```

## MIDI rack

The console also exposes a browser synth rack: oscillator blend, filter motion,
arp length, MIDI input, and a knobbable effects chain for drive shape, chorus,
Space Echo-style tape delay, compression, pan, and the highpass sweep. `Play` and MIDI note-on
messages feed short Web Audio voices into a persistent generated AudioWorklet
effects rack, while `Render` and `WAV` use the deterministic offline renderer
for the longer phrase. In browsers with Web MIDI, click `Enable MIDI`, choose an
input, then play notes on a keyboard. With `Track arp root` enabled, the
`Euphoric pluck` arpeggiator retunes to the key you hold.

## Wavetable and FM

Classic saw, square, and triangle oscillators are rendered with PolyBLEP
anti-aliasing in `render()` and generated worklets. For richer sources, build a
wavetable bank from partials, single-cycle samples, or decoded browser audio;
then use it directly or inside a six-operator FM patch.

```ts
import { pipe } from '@stopcock/fp'
import {
  createWavetable,
  effects,
  fm,
  filter,
  instrument,
  operator,
  oscillator,
  render,
  sampler,
  wavetableFromAudio,
} from '@stopcock/synth'

const glass = createWavetable({
  partials: [1, 0.72, 0.38, 0.18, 0.08, 0.03],
})

const bell = fm({
  freq: 110,
  index: 1.8,
  operators: [
    operator.sine({ ratio: 1, level: 1, output: 0 }),
    operator.wavetable(glass, { ratio: 2, level: 0.42, output: 1 }),
    operator.sine({ ratio: 3, level: 0.18, output: 0.22 }),
  ],
  matrix: [
    [0, 1, 0, 0, 0, 0],
    [0, 0, 0.35, 0, 0, 0],
  ],
})

const patch = pipe(
  bell,
  filter.lowpass(3800, 1.2),
  effects.ensembleChorus({ rate: 0.3, depth: 4.44, mix: 0.35 }),
)

const samples = render(patch, { duration: 1.2, sampleRate: 48000 })

// Browser import stays explicit: decode the file first, then hand synth audio data.
const imported = wavetableFromAudio(await audioContext.decodeAudioData(arrayBuffer), {
  fundamentalHz: 110,
})
const sampled = oscillator.wavetable(imported, 220)
```

## Rust-native instruments

The first instrument primitives are Rust/WASM-native sources:
`instrument.acidBass()` for mono bassline patches, and `instrument.drumVoice()`
for kick, snare, and hat hits. `instrument.stringMachine()` adds a stereo
divide-down-style string source with a built-in ensemble stage, while
`instrument.polySynth()` adds a Juno-style stereo subtractive voice with
polyBLEP saw/pulse, sub oscillator, noise, resonant low-pass, ADSR shaping, and
chorus width. `instrument.lofiSampler()` combines zone-based sample playback
with 12-bit-style quantization, sample-hold downsampling, deterministic noise,
tone loss, and drive for older drum-sampler color. They share the same live
AudioWorklet runtime as effects, so trigger velocity and parameter automation
stay inside the Rust DSP path.

```ts
import { instrument, render } from '@stopcock/synth'

const acid = instrument.acidBass({
  wave: 'square',
  freq: 110,
  cutoff: 680,
  resonance: 0.72,
  envMod: 0.82,
  decay: 0.11,
  accent: 0.55,
  slide: 0.2,
  drive: 0.3,
  level: 0.8,
})

const samples = render(acid, {
  duration: 1,
  sampleRate: 48000,
  triggers: [
    { midi: 36, velocity: 0.95, atSec: 0, gateMs: 120 },
    { midi: 43, velocity: 0.62, atSec: 0.25, gateMs: 90 },
    { midi: 48, velocity: 0.88, atSec: 0.5, gateMs: 140 },
  ],
})

const drums = [
  instrument.drumVoice({ kind: 'kick', decay: 0.38, snap: 0.65, drive: 0.18 }),
  instrument.drumVoice({ kind: 'snare', decay: 0.3, snap: 0.72, noise: 0.88 }),
  instrument.drumVoice({ kind: 'hat', decay: 0.045, tone: 0.9, snap: 0.42 }),
]

const strings = instrument.stringMachine({
  attack: 0.22,
  release: 1.2,
  tone: 0.76,
  depth: 0.82,
  modulation: 0.52,
  width: 1,
})

const poly = instrument.polySynth({
  pulseWidth: 0.42,
  sub: 0.4,
  cutoff: 1400,
  resonance: 0.35,
  envMod: 0.45,
  decay: 0.18,
  sustain: 0.62,
  chorus: 0.55,
  width: 1,
})

const lofi = instrument.lofiSampler({
  zones: [{
    samples: new Float32Array([0, 0.9, 0.55, 0.12, -0.08, 0]),
    sampleRate: 48000,
    rootMidi: 48,
    keyLow: 36,
    keyHigh: 60,
    velocityLow: 0,
    velocityHigh: 1,
    pan: 0.2,
  }],
  bits: 12,
  downsample: 2,
  noise: 0.05,
  tone: 0.62,
  drive: 0.18,
  level: 0.85,
})
```

## Sampler instruments

Sampler zones are also graph data. Each zone carries its own sample rate, root
note, key and velocity range, loop points, gain, and pan, then the WASM runtime
does the pitch playback and looping in the same renderer used by the live
AudioWorklet path.

```ts
import { sampler, render } from '@stopcock/synth'

const body = new Float32Array([0, 0.8, 0.45, 0.1, -0.1, -0.03, 0])

const sampled = sampler.instrument({
  zones: [{
    samples: body,
    sampleRate: 48000,
    rootMidi: 48,
    keyLow: 36,
    keyHigh: 60,
    velocityLow: 0,
    velocityHigh: 1,
    loop: false,
    gain: 0.9,
    pan: -0.15,
  }],
  attack: 0.002,
  release: 0.08,
  level: 0.85,
})

const samples = render(sampled, {
  duration: 1,
  sampleRate: 48000,
  triggers: [
    { midi: 48, velocity: 0.9, atSec: 0, gateMs: 160 },
    { midi: 55, velocity: 0.62, atSec: 0.32, gateMs: 180 },
  ],
})
```

## Worklet handles

Generated worklets expose stable AudioParam names per node instance. The helper
functions throw a `SynthCompileError` when a lookup does not belong to the
current compiled module.

```ts
import { compileWorklet, workletParam } from '@stopcock/synth'

const module = await compileWorklet(ctx, bass)
const node = new AudioWorkletNode(ctx, module.processorName, {
  numberOfInputs: module.numberOfInputs,
  numberOfOutputs: module.numberOfOutputs,
  outputChannelCount: module.outputChannelCount,
  processorOptions: module.processorOptions,
})

const amount = workletParam(module, distortionNode, 'amount')
node.parameters.get(amount.audioParamName)?.setValueAtTime(0.7, ctx.currentTime)
```
