```bash
bun add @stopcock/fp
```

```ts
import { flow, pipe } from '@stopcock/fp'
import * as A from '@stopcock/fp/array'
import * as O from '@stopcock/fp/option'
import * as R from '@stopcock/fp/result'
```

## pipe

Pass a value through functions, left to right. If you chain array operations, they get fused into single loops automatically.

```ts
type User = { name: string; active: boolean; score: number }

const leaderboard = pipe(
  users,
  A.filter((u: User) => u.active && u.score > 0),
  A.sortBy((a: User, b: User) => b.score - a.score),
  A.take(10),
  A.map((u: User) => u.name),
)
```

Portable tagged operators can be planned into a single loop. `take(10)`
terminates early, so work stops after ten matching results.

## flow

Same as `pipe` but gives you a reusable function instead of running straight away.

```ts
const activeNames = flow(
  A.filter((u: User) => u.active),
  A.map((u: User) => u.name),
)

activeNames(usersA)
activeNames(usersB)
```

## Fusion

`pipe` recognizes tagged array operations and uses checked-in portable loop
templates. `take` and short-circuiting terminals can stop before the input is
exhausted.

```ts
const big = Array.from({ length: 1_000_000 }, (_, i) => i)

// visits ~70 items, allocates nothing intermediate
pipe(
  big,
  A.filter((x) => x % 7 === 0),
  A.map((x) => x * 2),
  A.take(10),
)
```

Operations that need the whole array (`sort`, `groupBy`, `uniq`) break the fusion chain. See [Fusion](/concepts/fusion) for the full picture.

## Dual signatures

Every function works both ways:

```ts
A.take(users, 5) // data-first
pipe(users, A.take(5)) // data-last
```

## Option and Result

```ts
pipe(
  O.fromNullable(user.email),
  O.map((e) => e.split('@')[1]),
  O.getOrElse(() => 'unknown'),
)

pipe(
  R.tryCatch(() => JSON.parse(input)),
  R.map((obj: { value: number }) => obj.value),
  R.getOrElse(() => null),
)
```

See [Option & Result](/concepts/option-result) for the full API, or try the [Cookbook](/cookbook) for more patterns.
