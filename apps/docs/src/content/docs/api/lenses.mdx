---
title: Lens migration
description: The 2.0 optic module replaces the old root lens helpers
---

The 1.x root lens helpers were replaced by the unified
`@stopcock/fp/optic` module. Import the module explicitly:

```diff
- import { prop, view, set, over } from '@stopcock/fp'
+ import * as Optic from '@stopcock/fp/optic'

- const name = view(user, prop<User, 'name'>('name'))
+ const name = Optic.view(Optic.prop<User, 'name'>('name'), user)

- const updated = over(user, prop<User, 'name'>('name'), String.toUpperCase)
+ const updated = Optic.modify(
+   Optic.prop<User, 'name'>('name'),
+   user,
+   String.toUpperCase,
+ )
```

The new module covers lenses, optionals, prisms, traversals, isomorphisms,
getters, folds, setters, keyed `At` optics, composition, a fluent builder, and
law helpers. Read the [Optic API](/api/optic).
