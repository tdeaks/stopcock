---
title: Dict migration
description: Dict was replaced by Record in @stopcock/fp 2.0
---

The 1.x `D` namespace and `/dict` subpath were removed. Use the property-key
aware record module:

```diff
- import { D } from '@stopcock/fp'
+ import * as Record from '@stopcock/fp/record'

- D.toEntries(values)
+ Record.entries(values)
```

The new module includes immutable `get`, `set`, `remove`, `modify`, `update`,
`map`, `filter`, `filterMap`, `mapKeys`, `merge`, `pick`, `omit`, `partition`,
`reduce`, and equality operations. Bulk construction and transforms have
explicit `fromEntriesInto`, `mapInto`, and `filterInto` forms.

Unlike the old string-only `Dict` vocabulary, records preserve enumerable
`PropertyKey` values, including symbols.
