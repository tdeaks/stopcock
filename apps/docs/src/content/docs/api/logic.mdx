---
title: Logic migration
description: Logic was split into focused function and guard modules
---

The broad 1.x `Logic` namespace was removed from the 2.0 public surface.

Use `@stopcock/fp/function` for function-level composition:

```ts
import * as Fn from '@stopcock/fp/function'

Fn.complement(predicate)
Fn.ifElse(predicate, onTrue, onFalse)
Fn.always(value)
```

Use `@stopcock/fp/guard` for predicate and refinement composition:

```ts
import * as G from '@stopcock/fp/guard'

const nonBlank = G.and(G.isString, G.isNonBlankString)
const stringOrNumber = G.or(G.isString, G.isNumber)
const notNullish = G.not(G.isNullish)
```

Use `@stopcock/fp/eq` for domain equality, `@stopcock/fp/match` for lightweight
tagged-data dispatch, or the full `@stopcock/pattern` companion for structural
and exhaustive pattern matching.
