---
title: Server Timing
description: Emit Server-Timing headers from app and route plugins
---

```bash
bun add @stopcock/server
```

```ts
import { serverTiming, timing } from '@stopcock/server/timing'

defineApp({
  modules: [ApiModule],
  plugins: [serverTiming()],
})

route.get('/expensive')
  .use(timing())
  .handler((ctx) => {
    ctx.timing.mark('db')
    return { ok: true }
  })
```

Use the app plugin for total request duration, and the route plugin when handlers need to mark named spans.
