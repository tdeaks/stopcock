---
title: Bearer Auth
description: Typed bearer token route plugin
---

```bash
bun add @stopcock/server-bearer
```

```ts
import { bearer } from '@stopcock/server-bearer'

const withAuth = bearer({
  verify: async (token) => ({ userId: token }),
})

route.get('/me')
  .use(withAuth)
  .handler((ctx) => ctx.auth.userId)
```

The return type of `verify` becomes `ctx.auth`. Missing or malformed headers throw `Unauthorized`, and the plugin adds auth metadata for OpenAPI.
