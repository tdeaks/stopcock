---
title: CORS
description: App-level CORS plugin with preflight handling
---

```bash
bun add @stopcock/server-cors
```

```ts
import { cors } from '@stopcock/server-cors'

defineApp({
  modules: [ApiModule],
  plugins: [
    cors({
      origin: 'https://example.com',
      credentials: true,
      maxAge: 86400,
    }),
  ],
})
```

The CORS plugin handles `OPTIONS` preflight at the edge, even when no application route matches, and adds CORS headers to normal and error responses.
